# Mi Card App

A clean and responsive personal business card application built with **Flutter and Dart**. The project demonstrates fundamental Flutter UI development, widget composition, custom typography, and local asset management.

## Features

* Personal profile card with avatar and professional title
* Contact information displayed using reusable Card and ListTile widgets
* Custom fonts and typography
* Local image and font asset integration
* Clean and responsive Material UI

## Tech Stack

* **Flutter**
* **Dart**
* **Material UI**
* **Custom Fonts**
* **Local Assets**

## Key Learnings

* Building user interfaces using Flutter's widget-based architecture
* Working with `Column`, `Card`, `ListTile`, `CircleAvatar`, and `Text` widgets
* Managing layout using alignment and spacing properties
* Integrating custom fonts and local image assets
* Applying consistent styling using `TextStyle` and Material design components

## Getting Started

### Prerequisites

* Flutter SDK
* Dart SDK
* Android Studio or VS Code

### Installation

```bash
git clone https://github.com/Ayush-S-Patil/Mi-Card-App.git
cd Mi-Card-App
flutter pub get
flutter run
```
